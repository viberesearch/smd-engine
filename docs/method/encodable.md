## 8.3 Procedures

1. Reflexive exit (steps in 2.4) [GP1975].
2. Problematization with plus/minus marking of scheme blocks (5.2) [GP-PP].
3. Paradox test: two contradictory statements, both justified → problem; one right one wrong → error [GP-Guide9].
4. ОДИ dynamic (4.4, steps 1–9) [GP1987].
5. Participant self-determination questions (4.5) [PG1987].
6. Daily reflection slot: general session, group results, next-day plan [PG-GT].
7. Object reconstruction: describe each position's activity first, then assemble via activity scheme [GP1981].
8. System unfolding in four planes, recursive on morphology [GP1974s].
9. ARIZ-85В parts 1–9 (6.3) [ARIZ85V].

## 8.5 Classic vs later adaptation (for tagging in the schema)

- Classic (GP, ММК, to 1994): items from GP1966, GP1974s, GP1974r, GP1975, GP1981, GP1983, GP1987, GP-PP, GP-SMD, GP-OP, GP-Guide9.
- Later (PG, Popov, Anisimov): four positions and their reduction; игротехник's three functions; the four through-processes; daily slot wording; seminar roles критик/организатор/арбитр.
- Unverified or program-specific: "такт"; "рамка" as a procedure; "онтологическая работа" as a defined procedure; a fixed canonical phase sequence for all ОДИ; the block list of the 1975 "разборный ящик"; BSY principles.
